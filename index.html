使用说明

新火 · AI 漫剧全流程创作工作台 · v2.0

1如何填写 DeepSeek API Key

  • 访问 platform.deepseek.com 注册账号并申请 API Key
  • 点击右下角 AI 助手按钮 → 齿轮设置 → 粘贴 Key → 点「测试连接」验证
  • Key 仅存本机浏览器 localStorage，不会上传任何服务器；请勿外泄
  • 模型默认 deepseek-chat（快速），可切换 deepseek-reasoner（深度推理，较慢）

2如何新建项目并走完 7 步

  • 侧边栏「工作区」→「项目」→ 点「新建项目」→ 填写名称、选择题材
  • 7 步固定流程：①剧本 → ②分镜脚本 → ③道具提取 → ④资产图 → ⑤分镜图首帧 → ⑥视频生成 → ⑦剪辑
  • 每步有「调用对应模板」按钮一键填入题材模板，「AI 生成」按钮自动生成内容
  • 未完成前置步骤时后续步骤锁定，不能跳步；上一步产出自动带入下一步「上游输入」区
  • 编辑器内容自动保存，刷新不丢

3AI 生成怎么用

  • 每个项目步骤编辑器上方有「AI 生成」按钮，按当前步骤自动构造专业提示词
  • ①剧本：注入题材爆款逻辑（开篇3秒钩子/反转密集/结尾悬念），生成约500字
  • ②分镜脚本：生成分段文本格式，含8节奏标签、镜头衔接、存在意义
  • ③-⑥：资产提取/资产图/分镜图/视频提示词，均注入对应模板规则+上游内容
  • 生成结果填入编辑器末尾，不覆盖已有内容；生成中可取消
若 AI 报 400 错误，看错误提示中的具体原因（如 content 字段缺失、token 超限），通常是上游内容过长或 Key 额度不足。

4产出库 / 剧档案怎么用

  • 侧边栏「工作区」→「产出库」，以「剧」为单位管理产出
  • 新建剧：填写剧名、题材、简介；剧内按类型分类（剧本/分镜/资产清单/资产图/分镜图/图片/视频/其他）
  • 项目详情页「归档为剧」按钮：一键把项目7步产出按类型自动归类为一部剧档案（复制快照，原项目保留）
  • 步骤编辑器「存入产出库」按钮：把当前步骤内容一键存入最近的剧档案
  • 支持类型筛选、搜索、详情查看、编辑、删除（需确认）

5壁纸怎么设置

  • AI 助手对话框头部 → 壁纸图标（在齿轮设置旁）→ 打开外观设置
  • 四种模式：默认纯色 / 内置渐变（3款）/ 图片URL / 本地上传 / 视频壁纸
  • 视频壁纸：同目录需存在 wallpaper_video_web.mp4（分发版附带压缩版约22MB）；加载失败自动尝试 wallpaper_video.mp4，都失败点「选择文件」选取本地视频
  • 暗化滑块（40-80%）保证文字可读；模糊滑块（0-6px）增强融合感
  • 设置存本机 localStorage，刷新不丢；「恢复默认」一键重置
部署到静态托管（GitHub Pages / Vercel 等）时，视频文件需一同上传；若单文件超100MB（GitHub Pages限制），请用压缩版 wallpaper_video_web.mp4。

6数据存储与清理提示

  • 所有项目、剧档案、壁纸设置、AI Key 均存在本机浏览器 localStorage，不上传任何服务器
  • 清理浏览器数据 / 换浏览器 / 无痕模式会导致数据丢失，建议定期手动备份重要剧本
  • 本工具为纯前端单文件应用，无后端、无账号、无云同步

7常见问题

  • 视频壁纸黑屏/不播放？ → 点「选择文件」按钮重新选取本地视频文件，或确认同目录有 wallpaper_video_web.mp4（部署版）/ wallpaper_video.mp4（本地版）
  • AI 生成报 400？ → 看错误详情，常见原因：Key 无效/额度不足、上游内容过长（自动截断）、模型参数异常
  • AI 生成报 401？ → API Key 无效或已过期，重新填写
  • 页面打开空白？ → 建议用 Chrome / Edge 最新版，双击 HTML 文件即可打开
  • 首页背景不显示？ → 首页插画已 base64 内嵌，任何环境必显示；若仍空白请刷新
